From draft to website.

  1. Use Save draft after editing. Choose Preview draft to see your changes locally.
  2. Choose Download content.json. Keep this file as a backup of all announcements, projects, and writing.
  3. In the website source repository, replace content.json with the downloaded file and commit the change. GitHub Pages publishes the update from the main branch.

Announcements share one chronological feed: the newest three appear on the homepage; every entry stays in the searchable archive. Projects appear in the Projects section, grouped by their category. Writing appears in Writing. This editor only keeps local drafts; visitors cannot change the published site.
